# 🐾 PawNest

A full-stack pet adoption platform that connects loving homes with pets in need, built with a modern JavaScript stack.

🔗 **Live Project:** [assignment-9-rust.vercel.app](https://assignment-9-rust.vercel.app/)

---

## 📖 Overview

PawNest makes pet adoption simple and accessible. Users can browse adoptable pets, view detailed profiles, and connect with shelters or owners to start the adoption process, while admins can manage pet listings and adoption requests from the backend.

## ✨ Core Features

- 🔐 User authentication (sign up / login)
- 🐶 Browse and search adoptable pets by category
- 📋 Detailed pet profile pages
- ❤️ Submit and manage adoption requests
- 🛠️ Admin dashboard for managing pet listings
- 📱 Fully responsive design

## ⚙️ Environment Variables

Create a `.env` file in the root directory and add the following:

```env
# Database
MONGODB_URI=your_mongodb_connection_string

# Auth
JWT_SECRET=your_jwt_secret_key

# App
NEXT_PUBLIC_APP_URL=http://localhost:3000
```

> Replace with the actual variables your project uses, and never commit your real `.env` file.

## 🚀 Getting Started Locally

1. **Clone the repository**
   ```bash
   git clone https://github.com/md-siam-kazi-dev/pawnest.git
   cd pawnest
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Set up environment variables**
   Create a `.env` file as shown above.

4. **Run the development server**
   ```bash
   npm run dev
   ```

5. **Open in browser**
   Visit `http://localhost:3000`
