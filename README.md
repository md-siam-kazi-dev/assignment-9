🐾 PawNest
A full-stack pet adoption platform that connects loving homes with pets in need, built with a modern JavaScript stack.
🔗 Live Project: assignment-9-rust.vercel.app
📖 Overview
PawNest makes pet adoption simple and accessible. Users can browse adoptable pets, view detailed profiles, and connect with shelters or owners to start the adoption process, while admins can manage pet listings and adoption requests from the backend.
✨ Core Features
🔐 User authentication (sign up / login)
🐶 Browse and search adoptable pets by category
📋 Detailed pet profile pages
❤️ Submit and manage adoption requests
🛠️ Admin dashboard for managing pet listings
📱 Fully responsive design
